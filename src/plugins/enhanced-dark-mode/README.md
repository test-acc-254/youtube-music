# Enhanced Dark Mode Plugin

A sophisticated dark mode plugin for YouTube Music that provides multiple dark color schemes with optional album color integration.

## Features

- **5 Premium Dark Schemes**: 
  - Deep Black: Pure OLED-friendly black theme
  - Charcoal: Traditional dark gray theme
  - Midnight Blue: GitHub-inspired dark blue theme
  - Warm Gray: Warm-toned brownish gray theme
  - Cool Gray: Cool-toned bluish gray theme

- **Album Color Integration**: Optional dynamic color mixing with album artwork
- **Smooth Transitions**: All color changes are smoothly animated
- **Enhanced Readability**: Optimized text contrast for each scheme
- **Customizable Mix Ratio**: Control how much album color blends with the base scheme

## Configuration Options

### Dark Color Scheme
Choose from 5 carefully crafted dark themes, each optimized for different preferences:

- **Deep Black**: Perfect for OLED displays, pure blacks for maximum contrast
- **Charcoal**: Classic dark theme with warm grays
- **Midnight Blue**: Developer-friendly dark blue tones
- **Warm Gray**: Cozy brownish tones for reduced eye strain
- **Cool Gray**: Modern bluish grays for a professional look

### Album Color Integration
Toggle whether the plugin should extract colors from album artwork and blend them with your chosen dark scheme.

### Album Color Mix Ratio
When album color integration is enabled, control how much the album colors influence the interface (0-100%).

## Usage

1. Enable the "Enhanced Dark Mode" plugin in the YouTube Music settings
2. Select your preferred dark color scheme from the menu
3. Optionally enable album color integration
4. Adjust the mix ratio to your preference
5. Enjoy your personalized dark experience!

## Technical Details

- Uses CSS custom properties for efficient theme switching
- Leverages the `color-mix()` function for smooth color blending
- Applies intelligent color processing to ensure readability
- Integrates seamlessly with YouTube Music's existing theming system

## Compatibility

- Works alongside other visual plugins
- Respects YouTube Music's native dark theme as the foundation
- Smooth transitions prevent jarring color changes
- Optimized for all screen types including OLED displays
